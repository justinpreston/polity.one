Personal home automation

Nest Home Integration

A private integration operated by its owner for the owner’s own Google Nest thermostats. It uses Google’s Smart Device Management API to retrieve authorized thermostat information and support personal home automation.

This application is for the owner’s personal use. It is not a public service and is not affiliated with or endorsed by Google.

Permissions

The owner selects the home and thermostats to connect through Google’s consent screens. Thermostat permissions allow reading device information and changing settings. The current setup test only reads the device list.
